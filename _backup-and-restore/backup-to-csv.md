# 📤 How to Export Your Precious Metals Data to CSV

Managing your collection of bullion, coins, and sales data in *Precious Metals Manager* is easy — and so is exporting it! Whether you're backing up your records, sharing them with an accountant, or analyzing them in Excel, exporting to CSV format is just a few taps away.

Here’s a step-by-step guide on how to export your data to a CSV file.

---

## ✅ What Is a CSV File?

A **CSV (Comma-Separated Values)** file is a simple and widely supported file format that stores tabular data. You can open it in:

* Microsoft Excel
* Apple Numbers
* Google Sheets
* Any text editor

---

## 🧭 What Data Gets Exported?

When you export to CSV, the app includes:

* **Transaction date**
* **Type of transaction** (Purchase or Sale)
* **Seller information**
* **Order and invoice details**
* **Item quantity and ID**
* **Bullion name, type, and metal**
* **Mint, purity, wear, and metal content**
* **Unit price, tax rate, and spot price**
* **Notes and assay status**

Each row in the CSV represents a specific transaction involving a bullion item.

---

## 🛠 How to Export Your Data

Follow these steps inside the app:

1. **Go to Settings**
   Tap the settings button on the "Tools" tab or on the sidebar if you are using the app from an iPad or Mac.

2. **Scroll to the “Backup” section**
   This is where you'll find all import/export options.

3. **Tap “Export Data to CSV**
   Look for the option labeled **“Export data to CSV**.

4. Select the location where the CSV file will be saved.

## 📁 What the CSV File Looks Like

The exported CSV has clearly labeled columns such as:

```
date,transaction_type,seller,seller_type,recipient,invoice,...
```

Each value is enclosed in quotes if needed (e.g. if it contains commas or line breaks), so it's compatible with all spreadsheet apps.

Example row:

```
"01/01/2023","SALE","","","Baz","","10","","1","8B0B4D...","10 grams bar",...
```

---

## 🔐 Is My Data Secure?

Yes. The app processes your data locally and only shares it when *you* export or send the file. You’re always in control.

---

## 🧰 Bonus Tip: Use CSVs for Analysis

You can use the exported file to:

* Track investment performance
* Build custom dashboards
* Share data with tax professionals
* Backup your collection
