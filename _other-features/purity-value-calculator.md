With the **Purity Value Calculator** in **Precious Metals Manager**, you can enter weights of different purities and instantly estimate their market value based on live spot prices.

Here’s how to use this feature and what it can help you do.

---

## ⚖️ What Is It For?

The Purity Value Calculator is perfect if you want to:

* Estimate the melt value of old jewelry or bullion
* Compare the worth of different purity levels
* Quickly calculate totals based on weight and purity
* Get real-time valuations using current spot prices

---

## 🔢 How to Use the Calculator

1. **Go to Tools → Purity Value Calculator**
   Tap on the **Tools** tab, then scroll to the **Calculators** section and select **Purity**.

2. **Choose a Metal**
   Use the segmented control to select **Gold**, **Silver**, or **Platinum**. This sets the available purity rows and spot price source.

3. **Pick a Unit**
   Tap **Troy Ounces** or **Grams** to match the unit you're using. The calculator updates values accordingly.

4. **Enter Weights**
   For each purity row (e.g., 14K, 18K, .999), enter the weight of your material. The app will calculate the corresponding value in real time.

5. **(Optional) Add Custom Purity**
   If you're a **Pro user**, you can input a custom purity and weight at the bottom row.

6. **Review the Total**
   At the bottom, you’ll see:

   * Total entered weight
   * Fine metal content
   * Melt value based on live spot price

## 🧹 How to Reset All Fields

Need to start fresh?

1. Tap **Reset** in the top-right corner of the screen.
2. All weights and values will return to zero.

---

## 💡 Tips & Notes

* Spot prices update automatically and reflect your **selected currency**.
* The calculator does **not account for wear, refining losses, or dealer fees** — use it as a base valuation.
* You can mix different purities in one calculation — great for bulk estimates.

---

## 🚀 Pro Features

Upgrade to **Pro** to unlock:

* Manual entry for custom purities
* Switching between metals
* Switching between troy ounces and grams
