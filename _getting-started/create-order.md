> Orders must be created before adding items to your inventory.

1) In the Orders tab, tap "+" button to open up the page to add your order.

{% include theme-image.html
   data_light="/assets/images/light/getting-started/create-order/orders_light.webp"
   data_dark="/assets/images/dark/getting-started/create-order/orders_dark.webp"
   alt="Add order button" %}

2) The input page for registering a new order consists of:

* Seller: select from your saved seller presets. If no preset is selected, a Seller Name field appears and a new seller will be created automatically on save.
* Invoice Number (Optional): only shown when the selected seller type is Dealer or Refiner (hidden for Individual).
* Shipping Cost (Optional): defaults to zero.
* Order Date (Optional): defaults to today.
* Note (Optional)

All fields are optional. If you skip them, the order will be created with zero shipping cost and today's date.

{% include theme-image.html
   data_light="/assets/images/light/getting-started/create-order/create_order_light.webp"
   data_dark="/assets/images/dark/getting-started/create-order/create_order_dark.webp"
   alt="Order input parameters" %}

3) To create a custom seller preset tap on "Seller".

4) In the Sellers screen, tap "+" button to open up the page to create a new seller.

{% include theme-image.html
   data_light="/assets/images/light/getting-started/create-order/sellers_light.webp"
   data_dark="/assets/images/dark/getting-started/create-order/sellers_dark.webp"
   alt="Sellers" %}

5) The input page for registering a new seller consists of:

* Type (Dealer, Individual, Refiner)
* Name (required)
* Website/Forum link
* Add tags

{% include theme-image.html
   data_light="/assets/images/light/getting-started/create-order/create_seller_light.webp"
   data_dark="/assets/images/dark/getting-started/create-order/create_seller_dark.webp"
   alt="Create seller" %}

6) Tap on 'Save' to record your seller, and select it to use it in your new order.

7) Finally tap on 'Save' to record your order.
